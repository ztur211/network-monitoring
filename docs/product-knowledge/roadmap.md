# NodeScope Roadmap

## Available Now

- Native Avalonia desktop client with in-app account creation and sign-in
- Local-first appliance built on ASP.NET Core, PostgreSQL, PostGIS, and
  TimescaleDB
- GIS network map using Mapsui and appliance-hosted raster tiles
- Device inventory with location, category, floor, IP address, MAC address, and
  notes
- Device connections, fiber runs, ISP circuits, property hierarchies, and
  multiple properties per organization
- Native 3D BIM viewer with IFC import, device placement, live status, BCF issue
  handling, and network-only IFC export
- NativeAOT monitoring agent with one-time enrollment, ICMP and TCP probes, SNMP
  polling, status history, and metric charts
- Embedded appliance prober for installations that monitor their local network
  directly
- Live SignalR updates and workstation latency and bandwidth measurements
- Organization membership, OWNER and ADMIN invitation management, domain-based
  access requests, and scoped permissions
- Guided first-network onboarding
- Assistant chat surface with a deterministic troubleshooting fallback while
  provider-backed inference is unavailable

## Planned Features

- **Provider-backed assistant inference:** Network-aware answers generated from
  documented inventory, live status, and product guidance
- **Router integrations:** Direct Ubiquiti, MikroTik, and Meraki integrations for
  discovery and traffic data
- **Floor plan overlays:** Image-based indoor plans behind mapped equipment
- **Mobile apps:** Native iOS and Android clients
- **MSP operations:** Multi-appliance aggregation, fleet alerts, and coordinated
  backup visibility

When asked about planned features, describe them as planned or coming soon. Do
not describe them as currently available or available for purchase.

See [NodeScope Organizations](organizations.md) for the current first-run and
membership workflow.
